## 1. 한 줄 요약

**"들으면 옮는 음악"을 파는 레이블.** 뚱보균(Fat Virus)을 퍼뜨리는 보균자(Carrier)라는 이름을 그대로 세계관으로 만들고, 모든 그래픽을 **코드로 생성되는 비트맵 균**과 **계속 변이하는 글자**로 통일한다. 웹사이트는 이 세계관을 직접 만져볼 수 있는 곳(FVC Lab)까지 포함한다.

## 2. 왜 하는가 (목표)

| 목표 | 구체적으로 | 성공 기준 |
|---|---|---|
| 이름에 의미 부여 | "fvc"가 뭔지 아무도 모름 → Fat Virus Carrier 세계관으로 설명 없이도 기억되게 | 처음 본 사람이 30초 안에 "아, 전염되는 음악 레이블" 이라고 말할 수 있음 |
| 릴리즈마다 고유한 얼굴 | 앨범마다 디자인을 새로 하지 않아도, **시드(seed) 숫자 하나**로 커버·바이닐·스티커가 자동으로 나옴 | 새 릴리즈 등록 = JSON 한 줄 추가로 끝 |
| 레퍼런스 수준의 그래픽 | FISK의 구조감 + Golova/Creatura 포스터 + 글리치 타이포 배너의 밀도 | 포트폴리오에 올릴 수 있는 완성도 |
| 참여형 브랜드 | 1st Ave "Make Your Own Tools"처럼 브랜드 규칙 안에서 누구나 결과물을 만들어 봄 | Lab 툴에서 만든 이미지를 저장·공유 가능 (2단계) |

## 3. 브랜드 콘셉트

### 3-1. 이름 풀이 — 세 단어 모두 두 가지 뜻

| 단어 | 원래 뜻 | 음악 쪽 뜻 | 브랜드에서 쓰는 법 |
|---|---|---|---|
| **FAT** | 뚱뚱한 | fat beat, fat sound (두툼한 소리) | 두꺼운 사운드 + 통통한 균 캐릭터 |
| **VIRUS** | 바이러스, 균 | 바이럴, 귀에 박히는 노래(earworm) | 좋은 음악은 사람에서 사람으로 퍼진다 |
| **CARRIER** | 보균자 | 음반 = 소리를 담아 옮기는 매체 (sound carrier) | 레코드도, 레이블도, 듣는 사람도 전부 보균자 |

- 메인 카피: **Highly Contagious.**
- 서브 카피: Catch it. / Fat sound spreads. / Listen once. Carry forever. / No known cure.
- **사이트는 영어만 쓴다.** (2026-11-14 결정 — 한글 전부 제거)

### 3-2. 톤

- 귀엽게 장난스럽지만, **유치하지 않게**. 볼터치·웃는 입 같은 캐릭터 표현 금지. 감정은 **눈(크기·개수·시선)** 으로만.
- 병원·실험실 말투를 **패러디**하되, 공포·질병 이미지는 쓰지 않는다. (마스크, 방호복, 사망, 확진, 집단감염 같은 단어·이미지 금지)
- 브루탈리즘 + 맥시멀리즘: 굵은 선, 검은 바, 큰 글자, 작은 글자를 모서리에 촘촘히.

## 4. 비주얼 아이덴티티 요약

### 4-1. 핵심 요소 3가지

1. **뚱균 (Ttung-gyun) — 비트맵 균**
   시드 숫자 하나로 몸 모양·털·눈·얼룩이 정해지는 픽셀 이미지. 잉크(검정) + 별색 1가지. 같은 시드 = 항상 같은 균.
2. **변이하는 워드마크 (Infected wordmark)**
   F·V·C 글자가 0.9초마다 7가지 "균주"로 바뀜: 픽셀 → 구슬 → 외곽선 → 노이즈 → 블랙레터 → 세리프 → 와이드. 로고가 **절대 두 번 같은 모습으로 안 보이는 것**이 규칙.
3. **페트리 접시 (Petri dish)**
   FISK 레퍼런스에서 가져온 타원을 "균을 키우는 접시"로 재해석. 타원 안은 복사기 노이즈로 채움.

### 4-2. 레퍼런스와 가져온 것

| 레퍼런스 | 가져온 것 | 안 가져온 것 |
|---|---|---|
| fiskprojects.com | 2단 카드 그리드, 얇은 선 표, 큰 타원 로고 푸터, 시계 | 빨간 고양이 마스코트, 그들의 색 |
| Golova 포스터 | 회색 바탕 + 2도 비트맵 이미지 + 모서리/세로 글자 | 원본 이미지 |
| Creatura 포스터 | 굵은 픽셀 이미지, 블랙레터+세리프 섞은 로고타입 | 로고 그대로 |
| Into the Noise (영상) | 글자 하나하나가 텍스처를 바꾸며 변이 | 구성 그대로 |
| Connwax Maniac | 검은 바 + 흰 글자, 노이즈 타원, 십자 마크, 겹쳐 쌓은 타이포 | — |
| 글리치 타이포 배너 | 한 단어 안에 여러 서체, 두꺼운 외곽선, 흩어진 베이스라인, 본문을 텍스처로 | 문구·개미 그림 그대로 |
| 1st Ave "Make Your Own Tools" | 브랜드 전용 생성 툴, 툴 카드 레이아웃(좌측 스펙 패널) | — |

### 4-3. 색·서체 (자세한 값은 `docs/02_design-system.md`)

- 바탕: Paper `#E8E7E3` · Golova Grey `#D4D3CF` · Copy White `#F7F7F5` · Ink `#0B0B0B`
- 별색(작품당 1개): **FVC Coral `#FF5B47`** (기본) / Cobalt / Acid / Magenta
- 아웃브레이크 색(배너·스티커만): Acid `#A6FF00`, Magenta `#FF2DB4`, Red `#FF2A1A`, Yellow `#FFE800`
- 서체: Inter Tight(정보) · Archivo 900 62%/125%(헤드라인/바) · Grenze Gotisch(블랙레터, 한 줄에 한 단어) · Instrument Serif Italic(곁말) · DM Mono(데이터)

## 6. 핵심 기능 정의

| 기능 | 설명 | 기술 메모 |
|---|---|---|
| 균 생성 `germ(seed)` | 시드 → 2도 비트맵 SVG | 서버에서 미리 렌더 가능 (빌드 타임) |
| 변이 글자 | 7(+melt/warp/contour 등) 균주로 글자 렌더 | 브라우저 캔버스 + 폰트 로드 후 생성, 이전엔 텍스트로 대체 |
| 눈 따라가기 | 히어로 균의 동공이 마우스 방향으로 이동 | requestAnimationFrame으로 최적화, 터치 기기는 천천히 자동 움직임 |
| Pressing Plant | 시드 → 스플래터 바이닐 + 센터 라벨 | 4색 팔레트 3종, 베이스 4종 |
| Colony | 균 실루엣 안을 크기 다른 원으로 채움 | 팔레트 3종 |
| Mutator | 입력 글자 → 이웃끼리 겹치지 않게 균주 배정 | 최대 20자 |
| 배너 시리즈 | 6종 레이아웃, 1초마다 단어당 한 글자 변이 | `banners(seed, tick)` |
| 시계 | 서울 시간 실시간 | `Intl.DateTimeFormat` Asia/Seoul |

**모든 모션은 `prefers-reduced-motion`이면 정지**해야 한다.

## 7. 콘텐츠 & 데이터

- 콘텐츠는 1단계에서 `content/*.json` 파일로 관리 (Strain, Outbreak, Goods, Site).
- **시드가 원본이다.** 생성된 SVG는 저장하지 않는다.
- 아직 실제 정보가 없는 칸은 `[PLACEHOLDER]` / `null` — 화면에는 `[Artist]`처럼 대괄호로 보인다.
- 2단계(선택): Sanity 같은 헤드리스 CMS로 이전. 필드 구조는 지금 JSON과 동일하게 유지.

**새 릴리즈 등록 절차 (운영)**
1. `content/strains.json`에 항목 추가 (`id`, `seed`, `title`, `carrier`, `strainType`, `formats`, `isolated`, 트랙)
2. `/lab/germinator`에서 시드를 몇 개 돌려보고 마음에 드는 숫자를 `seed`에 기입
3. `coverStyle`(golova/creatura/glitch/connwax)과 `spot` 색 선택
4. 배포 → 커버·라벨·바이닐·OG 이미지 자동 생성

## 10. 리스크 & 대응

| 리스크 | 대응 |
|---|---|
| "바이러스" 표현이 무겁게 느껴짐 | 귀엽고 장난스러운 톤 유지, 질병·공포 단어/이미지 금지 리스트 운영 |
| 변이 글자가 폰트 로드 전 깨져 보임 | 로드 전엔 텍스트 균주(wide/goth/serif)로 표시 → 로드 후 픽셀 균주 합류 |
| 모션 과다로 산만/성능 저하 | 화면 밖 섹션은 타이머 정지(IntersectionObserver), reduced-motion 정지 |
| 실제 콘텐츠 부재 | 플레이스홀더로 출시 가능하게 설계, 콘텐츠 들어오면 JSON만 교체 |
| 레퍼런스와 너무 비슷함 | 가져온 것/안 가져온 것 표(4-2)를 기준으로 리뷰 |
